Árvore de Decisão (Decision Tree)

1º - O Problema: Aprovar ou Reprovar

Considere o seguinte conjunto de dados:

Horas de Estudo Faltas Aprovado?
25Não
32Sim
16Não
41Sim
24Não

Nosso objetivo é prever se um aluno será aprovado com base nas características.

2º - Ideia da Árvore de Decisão

A árvore de decisão funciona como uma sequência de perguntas:

  • Cada pergunta é um nó
  • Cada resposta gera um ramo
  • O resultado final é uma folha (classe, que do nosso exemplo 'Sim' ou 'Não' para aluno aprovado)

Exemplo de pergunta:

Horas de estudo ≥ 3?

3º - Como Escolher a Melhor Pergunta?

Usamos uma métrica chamada Impureza de Gini:

\( Gini = 1 - \sum p_i^2 \)

Onde \(p_i\) é a proporção de cada classe.

4º - Cálculo da Impureza Inicial

No conjunto completo:

  • 3 alunos: Não
  • 2 alunos: Sim

\( p_{Não} = \frac{3}{5}, \quad p_{Sim} = \frac{2}{5} \)

\( Gini = 1 - \left(\left(\frac{3}{5}\right)^2 + \left(\frac{2}{5}\right)^2\right) \)

\( Gini = 1 - (0.36 + 0.16) = 0.48 \)

5º - Testando um Corte: Horas ≥ 3

Grupo 1: Horas ≥ 3

32Sim
41Sim

Todos são "Sim":

\( Gini = 0 \)

Grupo 2: Horas < 3

25Não
16Não
24Não

Todos são "Não":

\( Gini = 0 \)

6º - Impureza Após o Corte

Como ambos os grupos são puros:

\( Gini_{final} = 0 \)

Esse é um corte perfeito.

7º - Construção da Árvore

A árvore resultante pode ser representada assim:

            [Horas ≥ 3]
              /      \
           Não        Sim
          /            \
     Reprovado      Aprovado

Ou seja:

  • Se Horas ≥ 3 → Aprovado
  • Se Horas < 3 → Reprovado

Um exemplo de como poderia ficar com multiplos níveis:

                [Horas ≥ 3]
                  /      \
               Não        Sim
              /            \
     [Faltas ≤ 2]       Aprovado
         /      \
      Não        Sim
       /          \
    Reprovado    Aprovado

8º - Interpretação

  • A árvore aprendeu uma regra simples baseada nos dados.
  • Ela divide o problema em decisões menores.
  • Não precisamos de fórmula explícita como na regressão.

9º - Conceitos Importantes

  • Nó: pergunta (ex: Horas ≥ 3)
  • Ramo: resultado da pergunta
  • Folha: decisão final (Sim ou Não)
  • Impureza: mede o quão "misturado" está o conjunto

10º - Conclusão

Árvores de decisão funcionam criando regras simples baseadas nos dados. O modelo tenta dividir o conjunto de forma que cada grupo fique o mais puro possível.

Essa ideia é a base de algoritmos mais avançados como Random Forest e Gradient Boosting.
